01 / CONTEXT

Why this product exists

Financial dashboards often show many numbers without explaining the relationship between them. OripioFin needed to make the overview meaningful first and detailed second.

Who it is for

Individuals or financial operators who need a consolidated view of balances, financial activity, and portfolio performance without jumping between disconnected screens.

The design challenge

OripioFin is a financial dashboard concept that organizes balances, savings, investments, and activity into a single overview. The visual system uses a restrained interface and clear data grouping to make financial information easier to scan.

02 / PROBLEM

What needed to change

The design work starts by turning broad business friction into a small set of user-facing problems that can be prioritized and solved.

Problem statement

  • Users can lose context when numbers are presented independently.
  • Multiple financial categories need a consistent visual hierarchy.
  • Trend information should support decisions rather than decoration.
  • The dashboard needs to work for repeated daily use.

Design hypothesis

Structure the dashboard around an overview narrative: total position first, category balances next, trends and activity after. Reusable cards and charts keep the system consistent as more financial modules are introduced.
